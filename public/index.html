⚠ Risk warning. LinkedIn forbids automated scraping. Using your own session cookie risks rate limits and, in rare cases, account suspension. Skip this section to keep using the public anonymous scraper.
How to copy your li_at cookie from Chrome
  1. Open linkedin.com and sign in.
  2. Open Chrome DevTools (Cmd+Opt+I) → Application tab → Cookies → https://www.linkedin.com.
  3. Find the row named li_at. Double-click its Value column and Cmd+C.
  4. Paste below. The value typically starts with AQED and is ~200 characters.
  5. Cookies expire every few weeks. When scrapes start failing, repeat these steps.
